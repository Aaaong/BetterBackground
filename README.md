# Better Background

Chromite's background features as a mod of their own, until Chromite is released:

- **Weather background**: weather (sunny, light or heavy rain, snow, thunderstorm, fog), clouds, a starry night, shooting stars, sunset, fireflies, falling leaves in the season's colours and grass, drawn behind the game and under every card and button.
- **Calm Balatro background**: slows or stills the game's swirling background and can soften its colours.
- **Fade between windows**: menus fade into each other instead of sliding up.

## Install

Needs [Lovely](https://github.com/ethangreen-dev/lovely-injector). Steamodded is optional.
Put the `BetterBackground` folder in your Mods folder (`%AppData%\Balatro\Mods`).

## Settings

Options > Settings > **Background**. With Steamodded the same page is also in the mod's config tab.
Settings are saved to `config/better_background.lua` in the game's save folder.

If Chromite is installed, Better Background switches itself off: Chromite has these features too.
